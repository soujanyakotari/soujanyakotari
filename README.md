### 🏦 [Automated Bank Reconciliation](https://github.com/soujanyakotari/automated-bank-reconciliation)

Reconciles **bank statements against internal ledgers** with a three-pass matching engine:

1. ✅ **Exact** match
2. 🔍 **Fuzzy** match (date / reference similarity)
3. 👀 **Amount-only** review

- Cleans messy data: currency symbols, mixed date formats, inconsistent columns
- Produces matched / unmatched reports and summary stats
- Built to **speed up month-end close**

- 📏 **Rules:** spend-spike z-scores, off-hours activity, structuring, transaction velocity
