## 🚀 Featured Projects

### 🏦 [Automated Bank Reconciliation](https://github.com/soujanyakotari/automated-bank-reconciliation)

`Python` `Pandas`

Reconciles **bank statements against internal ledgers** using a three-pass matching engine:

1. ✅ **Exact** match
2. 🔍 **Fuzzy** match (date / reference similarity)
3. 👀 **Amount-only** review

- Cleans messy real-world data: currency symbols, varied date formats, inconsistent column names
- Produces matched / unmatched transaction reports and summary statistics
- Built to **speed up month-end close**

---

### 🕵️ [Anomaly Detection for Fraud](https://github.com/soujanyakotari/fraud-detection-analysis)

`Python` `scikit-learn`

A **hybrid fraud-detection system** that combines:

- 📏 **Rules:** spend-spike z-scores, off-hours activity, structuring, transaction velocity
- 🌲 **Model:** Isolation Forest on behavioral features engineered per account
- 🎯 **Output:** a ranked, **explainable risk score** showing flagged transactions and the rules each one triggered
